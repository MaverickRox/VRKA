# VRKA Branding Assets

This directory contains the official visual branding assets and iconography for VRKA.

---

## Asset Breakdown

- `vrka.ico`: Multi-resolution Windows application icon (16px, 20px, 24px, 32px, 40px, 48px, 64px, 128px, 256px).
- `vrka-wolf-256.png`: High-resolution transparent PNG logo mark.
- `nav/`: Optimized navigation icons for the Qt 6 QML sidebar.
- `v2icons/`: UI control and format status icons.
