# Support

## Before opening an issue

1. Update yt-dlp through VRKA Settings.
2. Restart VRKA.
3. Test a second permitted public URL.
4. Confirm the source is not DRM-protected.
5. Review `KNOWN_LIMITATIONS.md`.
6. Collect sanitized logs.

## Include

- VRKA version/build;
- Windows version;
- installer or portable mode;
- media mode and selected options;
- whether cookies/browser verification were used;
- exact stage that failed;
- sanitized Activity Stream;
- whether the problem reproduces after updating yt-dlp.

## Never include

- passwords;
- cookies;
- browser databases;
- tokens;
- authorization headers;
- signed URLs;
- private media;
- personal paths unless redacted.

Use the issue forms in this repository. Security issues belong in private vulnerability reporting, not public Issues.
